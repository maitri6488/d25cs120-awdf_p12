    🧠 How GitHub Actions CI Works

    1. Step 1: Developer runs git push origin main.
    2. Step 2: GitHub automatically detects .github/workflows/ci.yml and spins up an Ubuntu cloud virtual machine.
    3. Step 3: Runner checks out repository, sets up Node.js 18, and executes npm install.
    4. Step 4: Runner executes npm test. If assertions pass, a Green Checkmark (✔) is awarded; if any test fails, an immediate Red X (❌) alert is flagged!
